# MDIA — Medical Document Intelligence Agent / وكيل قراءة المستندات الطبية

برنامج محلي يقرأ ملفات PDF طبية (عربي/إنجليزي، نصية أو ممسوحة) ويستخرج بيانات منظمة، **كل قيمة مربوطة بدليلها** (صفحة + نص + إحداثيات + طريقة + ثقة).
لا يرسل أي مستند إلى خدمة خارجية، ولا يستخدم نموذج لغة؛ الاستخراج قائم على القواعد والتخطيط، لذلك لا يمكن لنص داخل المستند أن "يوجّهه".

## التشغيل
```
pip install -r requirements.txt        # + تثبيت Tesseract مع بيانات اللغة العربية (ara)
python -m mdia.server                  # http://127.0.0.1:8000
```
Windows 11: `run_windows.bat`  ·  Docker: `docker compose up --build`
متغيرات: `MDIA_DATA_DIR, MDIA_PORT, MDIA_API_TOKEN, MDIA_OCR_LANG, MDIA_TESSERACT_CMD, MDIA_MAX_UPLOAD_MB`
تقرير PDF بالعربية يحتاج `arabic-reshaper` و`python-bidi` وخط Amiri (مجلد `fonts/` أو خطوط النظام)؛ وإلا يفشل التصدير بوضوح بدل إنتاج رموز غير مقروءة.

## واجهة API
`POST /api/upload?filename=x.pdf&ocr=auto|force|off` (جسم الطلب = ملف PDF خام) ← `{job_id}` · `GET /api/jobs/{id}` · `/result` · `/pdf` · `/pages/{n}.png` ·
`POST /api/jobs/{id}/corrections` · `POST /api/jobs/{id}/reprocess` · `GET /api/jobs/{id}/export?format=json|csv|xlsx|pdf` · `GET /api/schema`

## المبادئ
لا استنتاج (التشخيص لا يُشتق من الدواء أو التحليل) · الأرقام الأصلية لا تُعدَّل أبدًا (الخلل الحسابي يُسجَّل فقط) · التواريخ الملتبسة (يوم/شهر، هجري) تبقى بلا قيمة منظمة ·
الصفحات المتطابقة لا تُحتسب مرتين · النصوص الشبيهة بالتعليمات داخل المستند تُسجَّل كتحذير وتُتجاهل · التصحيحات اليدوية تُحفظ منفصلة عن النتيجة الأصلية.

## دعم العربية — كيف يعمل وكيف تتحقق منه
- طبقة النص في PDF العربية تُخزَّن بطرق مختلفة (ترتيب بصري معكوس، أشكال عرض متصلة FExx، أو ترتيب منطقي)؛ القارئ يكتشف الاتجاه بالتصويت على مفردات طبية/مالية ويعيد الكلمة لترتيبها المنطقي، مع الحفاظ على الحرف المركّب (لا/لأ) وعلامات الترقيم الملتصقة والأرقام اللاتينية داخل النص.
- الأرقام الهندية (٠-٩) والفواصل العربية (٫ ٬) تُقرأ وتُنظَّم رقميًا مع الاحتفاظ بالنص الأصلي كما طُبع؛ والنطاقات المرجعية في سياق عربي (مثل ١٣٫٠ - ١٧٫٠) تُعاد لترتيبها الصحيح.
- التشكيل والتطويل لا يمنعان التعرف على الحقول؛ العملة الملتبسة («ريال») لا تُخمَّن؛ التاريخ الهجري أو الملتبس لا يحصل على قيمة منظمة.
- **شغّل على جهازك:** `python -m mdia.doctor` — يتحقق فعليًا من Tesseract + نموذج `ara`، ومن دورة OCR كاملة على نص عربي مُولَّد، ومن arabic_reshaper/bidi/خط Amiri، ويبني تقرير PDF عربيًا ويعيد قراءته (ويحفظ `mdia_doctor_report.pdf` لتتأكد بعينك من اتصال الحروف واتجاهها). الواجهة تحذّر أيضًا إن غاب نموذج `ara`.

## ما تم التحقق منه فعليًا (python -m unittest tests.test_pipeline tests.test_arabic، 42 اختبارًا)
انظر `reports/metrics.json`. الأرقام على **عينات اصطناعية أنشأها المطوّر** (15 ملفًا) وليست دقة عامة مضمونة على مستشفيات حقيقية.

## ما لم يُتحقق منه بعد / قيود معروفة
- OCR العربي (نموذج `ara`) وتشكيل العربية الحقيقي في تقرير PDF (arabic-reshaper/bidi) وخط Amiri لم تُختبر في بيئة التطوير (بلا شبكة)؛ اختُبر مسار الخط والتحقق بدالتين بديلتين فقط، وتغطية الخط المتاح لكل أشكال الحروف. استخدم `python -m mdia.doctor` للتحقق على جهازك.
- عيّنات العربية اصطناعية مولَّدة بمشكِّل حروف بسيط كتبتُه للاختبار (ثلاثة أنماط تخزين)؛ ملفات حقيقية من أنظمة مستشفيات قد تتصرف بشكل مختلف (مثل انعكاس الأقواس).
- Dockerfile وrun_windows.bat لم يُشغَّلا في بيئة التطوير.
- الكتابة اليدوية غير مدعومة بموثوقية؛ ستظهر بثقة منخفضة أو تُسجَّل كغير مقروءة.
- ترويسة جدول من سطرين، والجداول المتداخلة، وتخطيطات الفواتير غير المعتادة قد تحتاج إضافة مفردات إلى `mdia/lexicon.py`.
- حقول غير مغطاة حاليًا: الخدمات المصاحبة للإقامة، تاريخ التشخيص، تكلفة الأشعة من الفاتورة.
- التشفير على القرص غير مفعّل (الملفات بصلاحيات 0600 ومجلد خاص فقط).
