# MDIA — تجربة نماذج ذكاء اصطناعي مجانية لتحليل الجداول (2026-10-25)

## القرار
نفذنا تجربة منفصلة، **دون تغيير مسار PaddleOCR الافتراضي أو أي مبلغ مستخرج**. الهدف علاج أخطاء بنية الجداول العربية والإنجليزية التي ظهرت في 300 فاتورة اصطناعية.

### النماذج المختارة
1. **microsoft/table-transformer-detection** — اكتشاف مناطق الجدول داخل الصورة، MIT.
2. **microsoft/table-transformer-structure-recognition** — التعرف على صفوف وأعمدة الجدول، MIT.
3. **Qwen3-VL-2B-Instruct** — مرشح لمرحلة ثانية لفهم المستند بالكامل، Apache-2.0، حجمه حوالي 4.27 GB، غير مثبت ولم يُختبر في هذه المرحلة. لا تسمح ظروف GitHub CPU المجانية الحالية باعتباره جزءًا إلزاميًا.
4. **PaddleOCR العربي الحالي** — يظل أساس قراءة النصوص العربية؛ لا نستبدله بنموذج غير مختبر.

الشيفرة الرسمية: https://github.com/microsoft/table-transformer ، وهو مستودع مؤرشف منذ 2026-09-21. الأوزان مجانية على:
- https://huggingface.co/microsoft/table-transformer-detection
- https://huggingface.co/microsoft/table-transformer-structure-recognition
- https://huggingface.co/Qwen/Qwen3-VL-2B-Instruct

## ما ثبت في GitHub
- `mdia/table_ai.py`: منفصل تمامًا عن محرك OCR والقيم المالية، يُحمّل نماذج التعرف عند طلب التجربة فقط؛ يستخرج مناطق الجداول وصفوفها وأعمدتها بإحداثيات نسبية وتقدير ثقة.
- اختبارات تعمد رفض إحداثيات الصفحة الخاطئة والثقة غير الصالحة؛ لا نسمح بإنتاج سعر/كمية من بنية الصفوف وحدها.
- `scripts/ai_table_model_pilot.py`: يشغل النموذجين فعليًا على 12 ملف PDF اصطناعيًا من 6 تخطيطات (بعضها blur/JPEG)، ويحفظ JSON وPDF والصور المميزة بالمربعات الملونة.
- `.github/workflows/mdia-ai-table-model-pilot.yml`: اختبار انحدار واثنان CPU لتشغيل النموذجين الحقيقيين، من دون خدمات مدفوعة.
- لا تشمل التجربة ملفات مرضى حقيقية أو أي API يتلقى محتويات الملفات؛ يستعمل النموذجان محليًا بعد تنزيل الأوزان العامة.

## بوابة القبول
لا يُحسب استخراج الصفوف نجاحًا إلا بعد الاطلاع على الصور وقياس اكتشاف الصفوف مقابل **صفوف الفواتير الأصلية**. الجدول البصري المقترح ليس OCR؛ ولا يمكن اعتبار رقم داخل صف سببًا لاعتماد القيمة. أي دمج لاحق يتطلب أن يحسن دقة الكميات والأسعار على مجموعة مستقلة من الـ300، دون زيادة أخطاء مالية.

## حدود التنفيذ
- النماذج مدربة في الأغلب على جداول أكاديمية؛ الأداء في المستشفيات العربية غير مضمون.
- هذه تجربة نموذج حقيقي، لا تُعد تطبيقًا نهائيًا حتى تظهر سجلات GitHub Actions وتُراجع نتائج الصور.
- عدم استخدام Python pip scripts من أطراف خارجية دون مراجعة؛ تُنزّل الأوزان فقط عند تشغيل Pilot.
- لا Merge ولا Deploy. احتفظنا بـmain دون تغيير.
