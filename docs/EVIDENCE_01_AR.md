# EVIDENCE-01 — توثيق مواقع الكلمات العربية والأدلة

**المستودع:** overurdream-collab/OCR_deepseak  
**الفرع:** experiment/paddleocr-arabic  
**الحالة:** تجربة تقنية، لا Merge ولا Deploy، ولا ملفات مرضى حقيقية.

## ما نُفذ فعليًا
1. حافظنا على النص الذي قرأه PaddleOCR دون استبدال قيمته بنتائج Tesseract.
2. أضفنا وضع مطابقة اختياريًا للحصول على موضع كلمة من OCR مستقل (Tesseract ara+eng). لا يقبل سوى كلمة مطابقة تمامًا بعد التطبيع، ثقة Tesseract >= 80، سطر Y متداخل، X قريب، ومرشح وحيد غير مكرر.
3. إذا لم تنطبق الشروط يظل المربع **تقديريًا**، ولا نخترع موضعًا.
4. معلومات الدليل `geometry_source` تميز `line_interpolated` من `cross_engine_word_match`. ويظل `word_box_verified=false` لأن توافق محركين لا يساوي Ground Truth للبكسل.
5. في الحالات التي يستخرج فيها الحقل جزءًا من سطر كامل، لا يُعامل مربع ذلك السطر باعتباره مربع كلمة مستقلاً.
6. الواجهة تعرض المربع التقديري بحد برتقالي متقطع، والمربع المطابق بمحرك ثانٍ باللون الأخضر مع بيان أنه غير معتمد بكسليًا.
7. أضفنا عزلًا لذاكرة التخزين بين الوضعين، ونتائج GitHub Actions منفصلة حتى لا تختلط بالاختبار القديم.
8. حالات الفشل لا تستبدل تلقائيًا بأي نص OCR آخر. المراجعة البشرية تظل مطلوبة لجميع مستندات PaddleOCR.

## التشغيل التجريبي
```bash
MDIA_OCR_ENGINE=paddle_arabic MDIA_PADDLE_WORD_ALIGN=1 python -m mdia.server
python -m unittest discover -s tests -p 'test_*.py' -v
```
يتطلب تشغيل PaddleOCR وتوفر Tesseract باللغتين `ara+eng`. الوضع الافتراضي للبرنامج لم يتغير.

## معايير القبول والحدود
- الاختبارات الآلية تغطي التطابق الإيجابي، سوء تطابق الكلمات، السطر والعمود الخطأ، الثقة المنخفضة، المرشحين المكررين، الأرقام القصيرة، وسلامة سجل الدليل.
- GitHub CI يشغّل محرك PaddleOCR الحقيقي على عينات عربية اصطناعية ويفصل نتائج المطابقة الجديدة عن baseline.
- **المقياس السابق 52/54** يؤكد القيمة والسطر في عينات اصطناعية فقط، وليس دقة الكلمة أفقيًا. لا يصح تحويله إلى نسبة دقة للموضع.
- مطلوب لاحقًا Ground Truth مستقل لمواضع الكلمات في الصور على محور X وY، وصور واقعية مجهولة الهوية متنوعة، والتحقق اليدوي من النقر داخل PDF.
- رقما الفاتورة الناقصان في اختبارات Paddle القديمة ما زالا ناقصين ولا يجوز تخمينهما.
- Docker/Windows لم يُختبرا ضمن هذه المرحلة.

**ممنوع تغيير المحرك الافتراضي أو اعتبار النظام طبيًا إنتاجيًا بمجرد نجاح CI.**
