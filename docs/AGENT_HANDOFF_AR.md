## 2) ما هو المنتج؟

MDIA (Medical Document Intelligence Agent) برنامج محلي لقراءة مستندات طبية وفواتير PDF العربية والإنجليزية، النصية والممسوحة، واستخراج بيانات منظمة مرتبطة بدليل المصدر: الملف/الصفحة/النص/الموضع/المحرك/الثقة.

المبادئ غير القابلة للتفاوض:
- المعالجة محلية؛ لا ترسل مستندات المرضى إلى خدمات خارجية.
- لا تخمّن القيم المالية أو الطبية، ولا تنشئ أرقاماً بالحساب أو الاستنتاج.
- احتفظ بالنص والقيمة الأصلية كما طبعت، وسجل التصحيحات اليدوية منفصلة.
- كل قيمة مهمة يجب أن ترتبط بدليل من الصفحة الأصلية.
- الغموض أو ضعف الدليل يعني مراجعة بشرية، لا ادعاء نجاح.
- نجاح اختبارات الوحدة لا يثبت دقة OCR على مستندات حقيقية.

## 7) التشغيل المحلي

ابدأ من تعليمات README. المسارات الرئيسية:
- تثبيت المتطلبات: `pip install -r requirements.txt`
- التشخيص: `python -m mdia.doctor`
- الخادم المحلي: `python -m mdia.server`
- Docker: `docker compose up --build`
- Windows: `run_windows.bat`

تحقق من توفر Tesseract وبيانات اللغة العربية أو PaddleOCR وأوزانه قبل تفسير نتائج OCR. إذا كان التشغيل دون إنترنت مطلوباً، اختبر بعد تنزيل الأوزان محلياً مع فصل الشبكة فعلياً. لا ترفع ملفات مرضى حقيقية إلى CI أو خدمات خارجية.

## 8) قواعد العمل للوكيل الجديد

- لا توسع نطاق المنتج إلى نموذج لغوي أو DeepSeek cloud أو GPU قبل إكمال إصلاح واختبار مسار OCR الحالي.
- لا تستبدل المحرك أو تعِد كتابة RTL/الجداول من الصفر قبل إثبات أن الكود الحالي لا يغطي الحالة.
- لا تحذف الاختبارات أو تخفف thresholds أو تستبدل بيانات الاختبار أو تستثني الحالات الفاشلة لإظهار نجاح.
- لا تستخدم بيانات اصطناعية على أنها دليل دقة على فواتير حقيقية.
- لا تدمج أو تنشر أو تغيّر إعدادات الأمان دون موافقة صريحة من مالك المشروع.
- لا تعمل بالتوازي عبر عدة فروع/وكلاء ثم تترك النتائج غير مدمجة. فرع عمل واحد، نتائج موثقة، وتسليم واضح.
