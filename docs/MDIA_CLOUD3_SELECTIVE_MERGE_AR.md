# MDIA Cloud 3 — Selective Merge / ملاحظات الاستلام

## نطاق العمل
- الفرع: `feat/mdia-cloud2-fixes` (بدون تعديل `main`).
- مصدر المقارنة: أرشيف المستخدم `mdia_agent_cloud 3.zip` مع مصدر Cloud 2 المحسن الموجود على GitHub.
- لا تعديل مباشر لفرعي `experiment/deepseek-ocr2-synthetic` أو `audit/mdia-cloud2-independent-qa`.

## التغييرات المنقولة
1. التخطيطات المركبة للجداول: ترويسات على سطرين، جدول مستمر دون ترويسة جديدة، أقسام الخدمات والخصومات.
2. المبالغ السالبة بين أقواس، والتحقق من إجمالي البنود قبل/بعد الخصومات.
3. كشف ميل الصفحات المصورة وتخزين مربعات الأدلة في إحداثيات الصورة الأصلية.
4. التنبيه عند تعارض أسماء المرضى رغم تطابق رقم الملف/التأمين.
5. اقتراح تصحيحات OCR العددية للعرض البشري فقط دون تغيير قيمة المستند.
6. تكلفة الإقامة مستخرجة من بند `Room Charges` المثبت.

## إصلاحات Cloud 2 التي تم الحفاظ عليها
- أسماء المرضى متعددة الكلمات: `mdia/kv.py` و`mdia/lexicon.py` لم تُستبدلا.
- استخراج سطر `Rx:` حتى من دون تركيز محدد؛ عدم تضمين `Rx:` ضمن اسم الدواء.
- استخراج مبدئي محافظ للفواتير العربية المصورة بلا ترويسات مع وسم المراجعة البشرية.
- تحذير `invoice_rows_not_verified` وإحالة المراجعة عند فقدان بنود الفاتورة.
- الاحتفاظ بآخر إصلاح لـ`mdia/doctor.py` كما كان على GitHub.

## الاختبارات
- تجربة الدمج المحلي على الملفات الاصطناعية: `python -m unittest discover -s tests -p 'test_*.py' -q` = **54 / 54 PASS**.
- تشمل الاختبارات السابقة و`tests/test_hard.py` مع مولد `tests/hard_samples.py`.
- يجب تأكيد GitHub Actions على أحدث SHA عند تنفيذ CI؛ لا تعتبر نجاح الإصدار السابق نجاحًا للإصدار المدمج.

## القيود الواضحة
- بيانات الاختبار اصطناعية. لا تعني نجاحًا على مستندات مستشفيات حقيقية.
- اختبار Windows وDocker لم يثبت ضمن اختبار الدمج المحلي.
- DeepSeek-OCR 2 ليس جزءًا من هذه الشيفرة ولم يُجر استدلال GPU.
- لا Merge ولا Deploy قبل مراجعة بشرية وبيئية نهائية.
