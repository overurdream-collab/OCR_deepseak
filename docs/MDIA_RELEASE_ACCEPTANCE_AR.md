## الأدلة المثبتة
- 300 فاتورة طبية اصطناعية مستقلة في ست مجموعات، PDF والصورة مطبوعة من حقيقة مرجعية.
- 300/300 تم تشغيل PaddleOCR CPU فعليًا عليها، 6/6 وظائف GitHub Actions SUCCESS، صفر أخطاء تشغيل.
- **4895/5776 = 84.75%** حقول مطابقة. هذه **نفس النتيجة القديمة** وليست تحسينًا مدّعى في OCR.
- 99 صفًا إضافيًا غير مطابق للمرجع ظهرت في المخرجات خلال الـ300؛ لا يجوز تمريرها إلى اعتماد مالي.
- 300/300 فاتورة عُلّمت بحاجة لمراجعة بشرية في ناتج القياس.
- فحص أدلة إضافي: كل مبلغ يطابق الدليل المرتبط بـ evidence_id، مع فحص صفحة/موقع الصف. الأرقام الموجودة في مكان آخر من الفاتورة لا تقبل كإثبات للسطر.
- مواضع كلمات PaddleOCR interpolated من صناديق السطور؛ **ليست** مستقلة التحقق، ولا يجوز وسمها كدليل هندسي قاطع.
- لم يُعدل المحرك مبلغًا، ولم يولّد تصحيحًا ماليًا تلقائيًا.

## تشغيل الإصدار
- Windows: `run_windows.bat` يُثبت محرك PaddleOCR CPU المجاني وينشط فحص الأدلة والحالات الناقصة. يلزم تثبيت Python 3.11 أو 3.12 وTesseract العربي.
- Docker: `docker compose up --build`، والوصول محلي فقط `127.0.0.1:8000`. اجتاز بناء الصورة وتشغيل واجهة API.
- أوزان PaddleOCR عامة تُنزّل للمرة الأولى؛ تُنفذ الاستدلالات محليًا دون خدمة OCR سحابية مدفوعة.
- لا يوصى بإرسال بيانات حقيقية إلى خدمة منشورة على الإنترنت دون مصادقة قوية وضوابط خصوصية.
